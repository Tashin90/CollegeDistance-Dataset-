# CollegeDistance Dataset — Introduction to Data Science Midterm Project

This repository contains an R-based midterm project built on the **CollegeDistance** dataset.  
The project focuses on practical data preprocessing, data quality improvement, exploratory analysis, and regression-oriented feature preparation.

## Project Files

- `College_dataset.R` — Main R script for preprocessing and analysis workflow.
- `CollegeDistance.csv` — Original/raw dataset.
- Processed CSV files generated during preprocessing and transformation steps.

## Completed Project Tasks

### 1) Missing Value Creation and Handling
- Created controlled missing-value scenarios for analysis.
- Applied missing-value handling strategies:
  - **Discard Instances**
  - **Mean/Mode imputation** (based on attribute type)

### 2) Noise Detection and Handling
- Checked and handled:
  - **Numerical noise** (unexpected numeric anomalies)
  - **Categorical noise** (inconsistent/invalid category values)

### 3) Invalid Data Checking
- Performed validation to detect logically incorrect or out-of-range values.
- Corrected or removed invalid records according to preprocessing rules.

### 4) Data Normalization and Transformation
- Applied normalization/transformation to prepare features for modeling.
- Ensured numeric attributes were on comparable scales where required.

### 5) Outlier Detection
- Identified outliers using statistical/visual techniques.
- Treated outliers according to the project’s preprocessing strategy.

### 6) Descriptive Statistics and Visualization
- Generated descriptive statistics to summarize central tendency and spread.
- Produced scatter plots to observe relationships between key variables.

### 7) Train/Test Split
- Split data into:
  - **80% Training set**
  - **20% Testing set**

### 8) Regression-Based Feature Selection
- Conducted regression-oriented analysis to evaluate and select influential features.
